📝 我的笔记

笔记保存在本浏览器，可一键云同步到 GitHub 仓库，换设备自动合并，永不丢失

☁️ GitHub 云同步

⚠️ 你的仓库是公开的！笔记是私密内容，请务必设置口令，云端只存密文，任何人（包括 AI 抓取）都看不到内容。换设备同步时输入同一口令即可解密。

怎么创建 Token（2 分钟）：

  1. GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. 点 Generate new token，填名称；Repository access 选 Only select repositories → 勾选本仓库
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. 生成后复制粘贴到上方输入框（Token 只存你本地浏览器，只发往 api.github.com）

同步原理：点赞/想法自动合并推送到仓库 data/notes.json；打开页面自动拉取合并，多设备互不覆盖
